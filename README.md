# howLLMworks:)

An interactive page that shows how a large language model reads text:
vocabulary, tokenizer, vectors, attention and next-word prediction.

**Live site:** https://howllmworks-vert.vercel.app

## What's inside
- Build your own vocabulary (BPE merges)
- See words split into subword tokens and IDs
- 3D graphs of spelling-based and context-based embeddings
- Next-word prediction with a temperature slider

## Run it locally
Download `index.html` and double-click it. No installs needed.
